How verification works
Agents run real CLIs against a fixed script, not an LLM. Hidden tests run after exit. Failures, unexpected file changes and leftover processes are retained. This measures runtime behavior, not coding ability.
One shared machine, one run at a time. Compare results and inspect the tests →
